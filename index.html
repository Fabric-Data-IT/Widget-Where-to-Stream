BB Media's Where To Stream widget is a tool that allows users to find where they can stream movies or series on different platforms. This component is ideal for integration into media and entertainment related websites, providing visitors with a quick and easy way to find out where the content they are looking for is available.

Integration Instructions

To add the widget to your website, follow these steps:

1. Add the Widget Container

Insert the following HTML code into the desired location on your webpage:

<div id="WhereToStream" wts-id="" wts-provider="" wts-type="" wts-country="" wts-tag=""></div>

wts-id Provide the ID from the source (IMDb, TMDB, TVDB, EIDR, BB Media).
wts-provider Identify the supplier with the appropriate code: imdb tmdb tvdb eidr bb
wts-type Specify the type of content (movie or series).
wts-country Enter the country code to find availability.
wts-tag Use a tag to reference your site or partner that BB Media delivered to you.


2. Add the Script Code

Include the Widget Script Add the following script tag to your HTML, ideally before the closing </body> tag: <script src="https://bb-media.com/widgets/where_to_stream.js"></script>

This script loads the widget functionality and ensures that it operates correctly on your page. Here is an example of how your HTML might look with the widget integrated: 

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Streaming Widget Example</title>
    </head>
    <body>
        <div id="WhereToStream" 
                wts-id="tt1520211"
                wts-provider="imdb" 
                wts-type="series" 
                wts-country="US" 
                wts-tag="example-site">
        </div>

        <script src="https://bb-media.com/widgets/where_to_stream.js"></script>
    </body>
</html>

Customize

To customize, you only need to dynamically or manually modify the following attributes. You can do it in real time on this website to see how it works; see the Customize panel on the right.

Attributes Description
wts-idReplace with the appropriate ID from your data source.
wts-providerReplace it with the appropriate provider.
wts-type Choose movie or series based on the content you want to display.
wts-country Use the ISO 3166-1 alpha-2 country code to specify the region.
wts-tag Tag provided by BB Media.
